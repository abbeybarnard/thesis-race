    You'll need a GitHub account. Pick how you write:

    1. Fill in the Join the race form and choose By hand. Add your thesis title if you'd like a silly racing nickname.
    2. Whenever you like, open Menu → Word Count in Overleaf and copy the total.
    3. Paste it into the Log my words form. Bookmark that link; it takes ten seconds.

    Using Overleaf's GitHub sync? Then the Thesis on GitHub route makes it fully automatic.

    1. Fill in the Join the race form and choose Automatic.
    2. Install the GitHub CLI and let it make gists: 
      gh auth login
gh auth refresh -s gist
    3. From your thesis folder, download the reporter and run it once: 
      curl -fsSLO https://raw.githubusercontent.com/OWNER/REPO/main/tools/thesis-race.sh
bash thesis-race.sh main.tex --hook

    --hook reports again after every git commit. Without git, run bash thesis-race.sh main.tex whenever you like, or add it as a VS Code task. It counts with texcount on your machine and sends only the total.

    1. Fill in the Join the race form and choose Automatic.
    2. Make a token with only the gist box ticked, and save it in your thesis repo as a secret called THESIS_RACE_TOKEN.
    3. Add this file to your thesis repo as .github/workflows/thesis-race.yml: 
      on: { push: {}, schedule: [{ cron: "0 22 * * *" }] }
jobs:
  count:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: OWNER/REPO@main
        with:
          main: main.tex
          token: ${{ secrets.THESIS_RACE_TOKEN }}

    Your repo can stay private. The count runs inside your own repo and only the number leaves it.

    Counts come from texcount or Overleaf, so they include headings and captions. Pages are estimated at 300 words each. The Very Hungry Caterpillar is about 224 words long.
